# Tom Emmerson Music Teacher — Static Site

This folder contains the files for the GitHub Pages site at https://thomasemmerson.github.io.

## What's included

- `index.html` — the homepage
- `styles.css` — the stylesheet
- `images/hero-studio.jpg` — the hero image
- `README.md` — this file

## How to publish to GitHub Pages

1. Open your GitHub repo: https://github.com/thomasemmerson/thomasemmerson.github.io
2. Upload the contents of this folder to the **root of the main branch**.
   - `index.html` must be at the root.
   - `styles.css` must be at the root next to `index.html`.
   - `images/hero-studio.jpg` must be inside an `images` folder.
3. GitHub Pages will publish the site within a few minutes.
4. Visit https://thomasemmerson.github.io to see it live.

## Adding more pages later

1. Create a new HTML file, for example `lessons.html` or `about.html`, in this folder.
2. Add a link to it in the navigation menu inside `index.html` (look for the `<nav>` tags near the top).
3. Re-upload the files to GitHub.

## Customising

- Edit `index.html` to change text, links or contact details.
- Edit `styles.css` to change colours, fonts or spacing.
- Replace `images/hero-studio.jpg` with your own image (keep the filename the same, or update the `src` in `index.html`).
